A tiny deterministic program that writes one museum label — the label a
museum in the year 3000 puts beside an ordinary object from today — to
`/output/entry.txt` for make.fun's Museum of the Year 3000 bounty.

The label it writes:

> Smoke alarm, c. 2022. A small god on the ceiling that screamed whenever toast was offered to it.

## Run it

```sh
python3 main.py
```

The program takes no input, reads no clock and no network, and writes
the same 96-character line on every run.
